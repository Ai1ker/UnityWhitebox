# Rotcev: vector lab

打开 `Assets/Whitebox/Scenes/MainMenu.unity`，点击 Unity 的 Play，从“开始游戏”进入第一关；构建版同样从主菜单启动。目前第一至第六关均已加入构建列表。全部画面使用本地生成的几何占位图，无外部素材依赖。要单独测试某关，也可直接打开该关场景后点击 Play。

## 主菜单、存档与结束界面

第一关默认开放，其余关卡按正常通关顺序逐关解锁，关闭游戏后保留。ESC 的关卡选择中，未解锁项会显示“未解锁”并禁止进入。设置中的“测试者选项 → 解锁全部关卡”默认关闭，勾选后可直接测试全部关卡；取消勾选后恢复正常解锁限制，测试模式中的通关不推进正式进度。测试关卡的存档在关闭测试模式后也不能绕过关卡锁。“开始游戏”清空正式通关与检查点进度，测试者开关作为设置保留。

`Prefabs/Mechanics/CollapseHazard.prefab` 是塌方机关，拖入场景并把顶板放在路线的上方。根物体的 `Box Collider 2D` 控制玩家触发区，`Delay Seconds` 控制进入后等待时间，`Segment Interval` 控制从左到右相邻板块坠落的间隔。顶板松动并亮红灯后坠落，砸中玩家扣除 100 HP；默认复活时复位。更多参数见同文件夹的 `CollapseHazard使用说明.md`。

主菜单提供“开始游戏”“设置”“退出游戏”，有有效存档时额外显示“继续游戏”。“开始游戏”清除旧进度并从第一关出生点开始；“继续游戏”直接加载最近保存的关卡，并恢复到该关最后激活的检查点位置。进入新关时也会记录该关出生点，因此尚未碰到检查点时继续游戏会从该关出生点开始。进度保存在本机，关闭程序后仍保留；设置中的改键和窗口模式与游戏进度分别保存。

存档记录关卡、检查点位置和该检查点的机关重置选项，不记录每个机关的即时状态；重新加载时使用场景默认机关状态。“脱离卡死”仍回到当前关卡最近的检查点。暂停菜单新增“返回主菜单”，已有进度会保留。通过 ESC 关卡选择或重新开始当前关卡时，从所选关卡出生点开始，并将它记为最新进度，不会自动恢复其他关卡的旧检查点。

最后的 `Prefabs/Mechanics/FinalExitPortal.prefab` 会传送至独立的 `Scenes/GameEnd.unity` 场景，显示“游戏结束”界面以及“返回主菜单”“退出游戏”按钮。结束界面停止玩法输入；返回主菜单后仍可通过“继续游戏”回到最后存档，重新进行末段测试。

`Prefabs/UI/MainMenu.prefab` 和 `Prefabs/UI/EndingMenu.prefab` 使用 uGUI Canvas、纯色 Image、Text 和 Button，右侧留有大块空白。以后可直接替换背景、图片、按钮和文字样式，保留 `WhiteboxFrontend` 组件及其 UI 引用；运行时默认装载中文字体，替换正式字体后可关闭 `Use Runtime Cjk Font`。主菜单“设置”复用原有改键和窗口模式界面，按 Esc 或“返回”回到主菜单。

## 音效与音量

主菜单或 ESC → 设置中的“音量”滑块控制全部声音，0% 静音，调整立即生效并在下次启动时保留。默认 80%。已接入机械脚步、跳跃、两个技能释放、散架死亡、炮塔瞄准和发射、子弹命中角色/墙面、存档点、压力板、子弹开关、门开关、传送和推箱摩擦。瞄准和推箱声音只在对应动作进行时持续，暂停、死亡和换关时停止；技能慢放不降低音效音调，传送声音可跨越关卡渐变。

声音文件位于 `ArtAssets/Audio/SFX`，以 CC0 地面脚步、金属撞击和拖擦实录为主体。脚步有 6 个短促、低音量变体，关节与擦地仅作轻微细节；推箱使用 5.8 秒真实摩擦循环，速度仅影响响度。两个技能保留机械触感，分别叠加短促和较低的双段电子脉冲，音量克制、柔和起落。原录音和许可证位于 `ArtAssets/Audio/Source/CC0`。在 Project 中选中 `Resources/LaboratoryAudio/SoundBank.asset`，可替换每项 Clips、调整 Volume 和 Pitch Variation；循环声需要首尾连续的素材。角色和现有关卡无需手动添加音源。`Tools/Rotcev/Audio/创建或补全音效库` 只补缺失项，不覆盖已修改的声音配置。

## 操作

| 输入 | 行为 |
| --- | --- |
| A / D | 左右移动，也可推动黄色方块 |
| W / 空格 | 跳跃；松开提前结束上升，短按低跳、长按高跳。两个键都按住时，松开其中一个不会截断跳跃 |
| S | 从蓝色单向平台向下穿过；实体地面不允许穿过 |
| 数字 1 | 进入速度方向瞄准；再次按 1 确认，扣 30 能量 |
| 数字 2 | 进入重力方向瞄准；再次按 2 确认，扣 40 能量 |
| 鼠标左键 | 选择道具、子弹，或技能 1 中选择玩家自身 |
| 左键拖动 | 从已选目标朝期望方向拖动；也可选中后在空处拖动 |
| 滚轮 | 随时拉近/拉远镜头，包括技能瞄准期间 |
| 右键 | 取消瞄准，不扣能量 |
| Esc | 打开/关闭暂停菜单；瞄准中打开菜单会取消该次瞄准，不扣能量 |
| 暂停菜单 → 脱离卡死 | 返回最近存档点；未激活存档点时回到本关出生点 |

暂停菜单的“设置”可分别修改左右移动、跳跃及备用跳跃、下穿、两个技能的按键，并切换窗口化/无边框全屏。点击某个按键框后按新键即可保存；Esc 在改键时取消选择，并始终保留给暂停菜单。重复按键会提示冲突；“恢复默认按键”可还原上表。设置会在下次启动游戏时保留。退出游戏在 Unity 编辑器中会结束 Play 模式，在构建版中会关闭程序。

暂停菜单的“关卡选择”可直接进入第一至第六关；当前关卡标记为“当前关卡 / 重新开始”，点击可从本关出生点重开。切换使用黑屏渐出、关卡标题与渐入效果，并恢复正常时间速度；新关卡的生命、能量及本关检查点重新初始化。在选择页按 Esc 或点“返回暂停菜单”可返回，游戏仍保持暂停。列表自动读取构建列表中启用、名称以 `Level` 开头的关卡场景，以后加入新关卡便会自动显示；主菜单和游戏结束场景不会出现在列表中。

菜单打开期间物理、能量回复、技能冷却、临时重力和开关门计时暂停；关闭菜单后继续。R 和 Shift+R 的快捷重置已移除。

右上角的机关教学提示只在第一关显示。技能瞄准/释放提示和临时消息位于右下角，避开底部操作栏；标题字号为 24，提示文字为 14，背景不透明度为 45%，文字不透明度为 85%。同时出现的提示会依次向上排列。

每个炮塔的 `WhiteboxTurret > Revive On Unstuck` 控制它是否在“脱离卡死”时恢复，默认关闭。对需要继续提供炮弹的炮塔单独勾选即可；勾选后会回到本次进入关卡时的场景初始位置和朝向，清零线速度、角速度和临时重力效果，恢复显示、颜色、炮管和碰撞体，并重新开始索敌。勾选但尚未摧毁的炮塔也会归位；初始未激活的炮塔不会被自动启用。初始位置按关卡内的实例摆放记录，不使用预制体资产的原点。未勾选的炮塔保持当前位置和摧毁状态，普通死亡不触发炮塔恢复。此选项独立于检查点的机关重置设置；脱离卡死仍会清除原有子弹。

炮塔摧毁后立即隐藏，不留下残骸，也不显示摧毁文字 UI。在 `WhiteboxTurret` Inspector 可选填“摧毁特效预制体”，并调整“特效保留时间（秒）”；留空则直接隐藏炮塔。有特效时，会在炮塔位置生成一次独立于炮塔层级的特效，炮塔隐藏后仍可播放，达到保留时间后自动清理。炮塔接触 `SpikePit` 地刺坑也使用同样的摧毁和特效流程。勾选 `Revive On Unstuck` 的炮塔仍可由“脱离卡死”恢复。

技能进入后全局时间降为 6%，角色不接收移动、跳跃、下穿输入，已有物理运动仍在慢放中继续。绿色箭头初始显示所选物体的实际速度方向或重力方向，调整后显示待释放方向。技能 1 不凭空提供速度，成功释放时保留目标当时的速度大小；静止物体会提示无法施放且不扣能量。角色释放自身速度方向后保留空中惯性直到实际接触地面，不再使用 0.38 秒的短暂保护。技能 2 禁止选择角色，地面和墙体不可选；重力方向只能选上、下、左、右，鼠标拖动会吸附到最近方向。

角色的空中运动采用统一的刚体重力，不再额外加快下落或把下落速度锁在 22。空中松开左右键不会主动刹车；同向按键不会把技能产生的高速运动降到普通跑速，反向按键以较弱的空中加速度逐渐调整速度。`WhiteboxPlayer > Air Acceleration` 默认 `10`，可调节空中操控力度，设为 `0` 时空中完全依靠已有速度和重力。落地后恢复原来的快速起停；普通跳跃仍支持短按低跳，技能转换的上升不会被松开跳跃键截断。撞墙等碰撞仍会由物理系统改变速度，箱子的速度上限和下压力设置保持原有规则。

两个技能各有独立的基础 1.0 秒冷却，从成功释放后开始，按现实时间计算；取消瞄准或释放失败不触发冷却。技能 1 对玩家自身释放时，每次使该次冷却额外增加 0.5 秒（第一次 1.5 秒、第二次 2.0 秒，以此类推）；玩家落地后累计加时清零，剩余冷却最多保留 1.0 秒。对其他目标释放技能 1 仍是 1.0 秒，技能 2 不受影响。左上角 HUD 显示每个技能的剩余冷却时间。

技能 2 的重力改向默认维持 5 秒，选中场景中的 `GameCore`，在 `Direction Skills > 技能 2 持续时间（秒）` 中可调整（字段 `gravityDurationSeconds`，最小 0.1 秒）。修改场景实例只影响本关，修改 `Prefabs/Core/GameCore.prefab` 可调整继承该值的关卡。持续时间从成功释放开始，按现实时间计算，暂停菜单打开时暂停计时；到期恢复目标原本的重力方向和重力强度，再次释放会按设定时长重新计时。子弹即使重力恢复，仍算玩家操控过的子弹，返回命中炮塔仍有效。

生命 100，能量上限 100，每个游戏秒回复 10 点（慢放时回复也随游戏时间减速）。只在有效施放成功后扣费。炮弹每发造成 25 点伤害，地刺立即致死；死亡自动回到最近检查点并恢复生命、能量。炮弹击中重力方块会按飞行方向给方块一个冲量，默认力度提高到 20，可在该方块的 `BulletLaunchReceiver > Launch Impulse` 中单独调整。箱子与地形使用较高摩擦系数；箱子的 `DirectionTarget > Lateral Damping` 只抑制相对重力方向的侧向滑动，不削弱反重力上升速度。玩家使用独立的低摩擦材质，走跳手感不会随之变粘。

## 教学路线

1. 出生区先练习走跳；地面上的蓝色平台可安全练习 S 下穿。
2. 跨越地刺上方四个平台，到达机关区检查点。
3. 把黄色方块从 x=31 推到 x=35 附近的黄色地面标记下。按 2 选中它，把绿色箭头改为向上，再按 2。方块在 5 秒内触碰天花板压力板后会吸附，右侧门持续开启。死亡后若回到机关区检查点，方块和门会一起重置。
4. 门后有一段缓冲区和第二个检查点。炮塔距离玩家 15 单位以内、没有墙体遮挡时用红色激光锁定 1.3 秒；可隔着可移动箱子锁定，然后发射橙色子弹。
5. 按 1 慢放，选中飞来的子弹，将方向指回炮塔后按 1。反射子弹击中一次即摧毁炮塔。继续向右进入绿色传送门，画面渐黑后加载第二关，再渐入空白场景。

技能 2 也可以改变子弹重力方向。被技能 2 操控后的子弹如果返回并击中发射它的炮塔，同样会造成一次命中并摧毁炮塔。

## 调整与替换

- `Scenes/Level05_Blank.unity` 的出口已连接第六关，保留原有布局和通关条件。`Scenes/Level06_Blank.unity` 只预置 `Player`、`Camera2D`、`GlobalLight2D`、`MainLight` 和 `GameCore`；角色出生在 `(0, 1)`，相机自由跟随。第六关没有预放地形、机关或最终出口，开始测试前先摆放出生区域地面，再按需要放入机制预制体。`Whitebox > Initialize Level 6 and Game Menus` 可检查新场景、预制体和构建配置，已有第六关和 UI 资产不会重新生成。
- `Prefabs/Mechanics/ForcedGravityBoundary.prefab` 是红色强制重力边界。动态物体的刚体中心进入区域后，包括箱子、玩家和子弹，其重力方向立即改为 `Forced Gravity Boundary > 强制重力方向` 所选的 `Down / Up / Left / Right`（下 / 上 / 左 / 右）。方向使用世界坐标四向；旋转边界改变范围形状，方向仍由 Inspector 选择。`Size` 以及根对象的位置、缩放和旋转调整判定范围，红色外框显示区域，重力方向在 Inspector 中调整，框内不显示方向线；它是触发区，不阻挡角色或箱子。离开后恢复进入前的重力机制；原有临时重力计时仍继续，若期间已到期则恢复原本重力。玩家处于红框内时不能发动技能 2，进入红框会取消进行中的技能 2 瞄准；红框内目标也不能被技能 2 改向，失败不扣能量或触发冷却。技能 1 保持可用。重叠边界以较大的 `Priority` 为准，相同优先级采用先启用的边界。
- `Prefabs/Mechanics/FinalExitPortal.prefab` 的造型沿用普通出口的旋转圆环和发光核心，放在最后一关终点即可使用。默认不附加通关条件；需要时勾选 `Require Turret Defeated` 或 `Require All Gates Open`。正常进入 `GameEnd` 场景，修改该场景里的 `EndingMenu` 预制体即可替换结束界面；`Ending Menu Prefab` 仅在结束场景未配置时作为备用。普通 `ExitPortal.prefab` 仍负责关卡之间的传送。
- `ArtAssets/` 是留给后续美术的空素材目录，可放入正式角色、机关、平台图片和 UI 图片。更换对应预制体的 SpriteRenderer 图片、视觉子对象或 UI Image，保留根对象的物理、触发区、脚本和关联引用；UI 也可在 `Prefabs/UI` 中单独换图和布局。
- `Prefabs/Mechanics/PressurePlatformSwitch.prefab` 是显现单向平台的独立压力板，预置 3 个 `OneWayPlatform_A` 平台，编辑时可见，开始运行时默认隐藏（碰撞也关闭）。玩家可踩在实体压力板上，玩家或箱子触碰即显示关联平台；持续压住会一直保持，所有物体离开后再延续 2 秒并隐藏。选中预制体根对象，在 `Pressure Platform Switch` 的 `平台 1 / 2 / 3` 中指定场景里的单向平台根对象，可留空、替换或删掉多余平台；`松开后持续时间（秒）` 控制延续时长。平台保留原来的跳上和 S 下穿行为。压力板的检测随位置、缩放和旋转变化，已吸附的箱子也能持续激活。暂停菜单冻结计时；重生/脱离卡死时遵循检查点的机关重置设置。`Whitebox > Create Pressure Platform Switch Prefab` 可检查预制体是否已生成，已有资产不会覆盖。
- `Scenes/Level04_Blank.unity` 的出口已连接第五关，保留现有炮塔通关条件。`Scenes/Level05_Blank.unity` 已加入构建列表和 ESC 关卡选择，只预置 `Player`、`Camera2D`、`GlobalLight2D`、`MainLight` 和 `GameCore`；角色出生在 `(0, 1)`，相机自由跟随，地形和机关留给你摆放。开始测试前先放置出生区域地面。`Whitebox > Initialize Level 5` 可重新检查连接和构建配置，已有第五关不会重新生成。
- `Scenes/Level03_Blank.unity` 的出口已连接第四关。`Scenes/Level04_Blank.unity` 已加入构建列表，只有 `Player`、`Camera2D`、两种光照和 `GameCore`；角色出生在 `(0, 1)`，相机自由跟随，地形和机关由你摆放。开始测试前先给出生区放置地面。
- `Prefabs/SceneHintText.prefab`：把提示文本框拖进场景，在根对象的 `SceneHintText > Content` 填写中文或多行文字；`Box Size` 调整文本框的世界宽高，`Font Size` 调整文字大小，`Padding` 调整内边距，颜色字段调整文字和半透明底板，`Show Background` 可隐藏底板。文字自动换行并在框内缩小以适配；可直接移动、旋转或缩放根对象。文本不参与碰撞、不拦截鼠标操作。
- `Whitebox > Initialize Level 4 and Hint Text Prefab` 可重新检查第三关出口和第四关构建配置；第四关或提示预制体已存在时不会重新生成它们。
- `Scenes/Level02_Blank.unity` 保留你已摆放的地形和机关，仅将现有出口的目标设置为第三关。`Scenes/Level03_Blank.unity` 已加入 Build Settings，只预置 `Player`、`Camera2D`、`Global Light 2D`、`Main Light` 和 `GameCore`，供你自行摆放地形和机关。第三关目前没有地面，开始游玩前请先放置出生区域地形。
- `Prefabs/Environment`：地面、墙体、天花板、单向平台、地刺坑。`Prefabs/Characters/Player.prefab`：可复用玩家。`Prefabs/Mechanics`：完整重力机关、压力板、门、炮塔和出口。`Prefabs/Core`：相机、照明和玩法系统。子弹与重力方块在 `Prefabs` 根目录。
- 第二关已有 `GameCore`、`Player`、`Camera2D` 和照明；直接在 Project 视图把预制体拖到 Scene 或 Hierarchy 即可，不需要再放第二套核心对象。拖入 `Mechanics/GravityPuzzle.prefab` 就是一整套独立的方块、压力板和感应门；复制它可以做多扇门，每套只控制自己的门和方块。要自行组合零件，则在 `PressureGate` Inspector 分别指定该组的 `Cube`、`Door Collider`、`Door Visual`、`Plate Visual`；`Wire` 可留空。压力板的位置、缩放和旋转共同决定实际检测区域；箱子接触地面或天花板压力板后会吸附并开门，不必先使用技能 2。选中 `PressureGate` 时，Scene 视图会画出压力板的判定框。
- 每个 `PressureGate` 在运行时显示青色矩形，表示该方块的活动边界。方块飞出矩形会回到这组机关的初始摆放位置；在该 `PressureGate` Inspector 调整 `Reset Horizontal Distance`、`Reset Below Spawn`、`Reset Above Spawn`，关闭 `Show Reset Boundary` 可隐藏边界。编辑模式下选中机关也能看到边界线。第二关相机默认自由跟随玩家；只在需要时于 `GameCore` 勾选 `Use Camera Bounds` 并设置 X 范围。滚轮随时缩放镜头；`GameCore` 的 `Min Camera Size`、`Max Camera Size`、`Zoom Step` 控制缩放范围与每格幅度。
- `Mechanics/MomentumResetBoundary.prefab` 是独立的橙色边界，无需添加 `PressureGate` 或原青色边界脚本。拖入场景后，把要控制的箱子拖到 `Cube`；箱子中心先进入橙色范围，之后离开才会自动归位，开局在范围外不会传送。开局在范围内则直接启用。归位保留线速度的方向、大小、角速度及当前重力状态。`Return Point` 留空、选择箱子自身或箱子的子对象，都使用箱子开局位置；指定独立的空对象时，则回到该空对象的当前位置。用 `Size`、边界根对象的位置、缩放和旋转调整范围；归位点可在边界外，此时归位后会重新等待箱子进入，避免连续传送。边界对象应独立摆放，避免跟随箱子移动。它不参与碰撞；每个箱子配置一套边界即可。绑定该箱子后，原 `PressureGate` 的青色自动归位边界会隐藏并暂停自动重置，等待首次进入期间也保持这一规则，其他箱子的边界不受影响；死亡/脱离卡死仍沿用存档点的机关重置规则。
- 箱子接触玩家头顶且受到向下重力时，会给玩家施加与箱子质量及重力强度相关的向下压力。侧面接触不产生该压力；地面仍正常支撑玩家，不造成额外生命伤害。玩家的 `WhiteboxPlayer > Cube Pressure Multiplier` 调整额外压力倍率，默认 `1`，设为 `0` 可关闭额外压力。
- 下压力会随箱子的向下速度增加：默认额外增加 `箱子质量 × 向下速度 × 6`，与原来的重力载荷一起计算，最终总下压力不超过 `150`。玩家的 `Cube Speed Pressure Multiplier` 调整速度影响，`Max Cube Downward Force` 调整压力上限。头顶撞击会短暂保留碰撞前的速度用于计算，侧面或向上运动不会增加这项速度压力。
- 箱子 `DirectionTarget > Max Speed` 设置最大总速度，默认 `30` 单位/秒。橙色边界继续保留速度方向和角速度，但超过上限时将总速度限制在这个值；重力加速和子弹冲量也受此上限约束。修改场景中的单个箱子可使用不同上限；玩家和子弹不受这项限制。
- `Mechanics/BulletSwitch.prefab` 与 `Mechanics/TimedDoor.prefab` 是两个独立预制体，可分别摆放。把门对象拖到开关的 `BulletSwitch > Door` 字段；每个开关只控制指定的门。子弹击中开关会开门 5 秒，再次命中会重置计时，时长在开关的 `Active Seconds` 调整。开关碰撞盒是触发区，玩家和箱子能穿过，且不会触发。旧的 `BulletSwitchDoor.prefab` 保留给已摆好的组合机关，其开关同样改为不挡玩家和箱子。出口可选 `Require All Gates Open`，勾选后要求所有重力感应门开启；`Require Turret Defeated` 会检查场景中所有炮塔。
- `Mechanics/Checkpoint.prefab` 是可放置的检查点，有半透明蓝色光柱与标记；玩家进入后变为绿色并持续闪动，表示已存档。移动预制体根对象决定触发位置，用 `Respawn Offset` 设置相对重生位置；`Reset Puzzles On Death` 决定死亡后是否重置重力机关和子弹开关。
- 场景中的地形、平台、方块、压力板、门和炮塔均为已保存的实体，可直接在 Hierarchy 中调整。
- `Scripts/WhiteboxPlayer.cs`：移动、跳跃、离地宽容与预输入；速度等可在 Inspector 调整。
- `Scripts/DirectionSkills.cs`：选择、全局慢放、方向编辑与释放。
- `Scripts/DirectionTarget.cs`：可选择物体及自定义重力；新道具需添加 Rigidbody2D、Collider2D 和该组件。
- `Scripts/WhiteboxGame.cs`：HP、能量、HUD、检查点与完成状态。
- `Scripts/PressureGate.cs`、`WhiteboxTurret.cs`、`WhiteboxBullet.cs`：机关与炮塔逻辑。
- `Prefabs/GravityCube.prefab` 和 `Prefabs/Bullet.prefab`：可复用占位预制体。
- 后续可替换 SpriteRenderer 的 sprite 和视觉子对象，保留根对象的物理与玩法组件。
- `Whitebox > Build First Level` 会重建默认白盒场景并覆盖该场景，手工调整后请先另存一份再使用。`Whitebox > Package Level 1 and Create Level 2` 可重新生成预制体与出口；已有第二关场景不会被覆盖。
- Play 模式下执行 `Whitebox > Run Play Mode Verification`，会用虚拟键盘和真实物理测试核心机制。结果写入 `Temp/WhiteboxVerification.txt`，也输出到 Console。验证期间请勿手动操作；完成后退出 Play 以还原关卡。
