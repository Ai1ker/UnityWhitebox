# PCM copies for offline editing

Kenney_ImpactSounds/*.wav are mono PCM16 copies decoded from the original Kenney OGG recordings retained under ../CC0/Kenney_ImpactSounds/Audio.

They retain the original CC0 license. Author, official source links, original package license and selected filenames are documented in ../CC0/SOURCES.md and ../CC0/Kenney_ImpactSounds/License.txt.

These WAV copies let Tools/generate_laboratory_sfx.py rebuild the game sounds with the Python standard library, without downloads or an external OGG decoder.
